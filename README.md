# SlimQuest

食事・体重・運動を素早く記録して、目標に向けた変化を見えるようにするアプリです。携帯電話での使用を想定していますが、PCのブラウザ上でも使うことができます。

- **使い方**: Chrome で https://rafysta.github.io/slimquest/ を開き、メニューから「ホーム画面に追加」
- **データ**: すべて端末内に保存しサーバーには何も送りません

## いまできること (v0.5.0 / Phase 1〜4 すべて)

### 記録する

- **食事の記録**: よく食べるものリストと、かな検索(「からあげ」「カラアゲ」「唐揚げ」のどれでも引ける)。
  タップ → 倍率(0.5/1/1.5/2)を選ぶだけで記録。同梱の食品データ約170件から探せます
- **新しいメニューの登録**: 手入力のほか、**AIがネット検索してカロリー・PFCの候補を出す**ボタンつき
- **バーコード読み取り**: 市販品はカメラでスキャン。登録済み → Open Food Facts → AI検索 → 手入力の順に照会し、
  一度登録すれば次からは読み取るだけ
- **セット**: いつも一緒に食べる組み合わせ(シリアル+プロテイン+牛乳など)を1つのメニューに
- **レシピ**: 自炊した料理を材料から登録。何人分作るか(既定2)で割った1人分が記録されます
- **体重の記録とグラフ**: 実測・7日移動平均・目標線・健康ペース帯(週0.5〜0.8kg)を1枚に表示
- **運動の記録**: METs方式のプリセット(自転車通勤・水泳・社交ダンスなど)。自転車通勤は平日に自動計上できます
- **1日のカロリー収支**: 基礎代謝 × 1.2 + 運動 − 目標赤字 を目安として、残りカロリーをリングで表示
- **食事日記**: 日送りで過去の記録を確認・削除
- **連続記録とバッジ**

### 献立を決める

- **手持ち食材リスト**: いま家にある食材を並べておくリスト。一度入力した食材は候補チップに出るので、次からはタップだけ
- **献立の提案**: 手持ち食材と最近食べたものからAIが料理を3〜5件提案。1人分の概算カロリーとPFC付き。
  材料は**手持ちにあるものが緑、足りないものがグレー**で出るので、いま作れるかが一目で分かります
- **買い物リスト**: 提案の「これにする」で足りない材料だけが自動で入ります。買えたものは1タップで手持ち食材へ

### 見た目の変化を追う

- **お腹の定点撮影**: ガイド枠と前回写真の半透明重ねで、同じ位置・同じ距離に合わせて撮影
- **変化ビュー**: スライダーと連続再生で見比べ。日付とその日の体重を重ねて表示

### 守る

- **バックアップ**: 記録・設定・お腹の写真をまとめて1つのZIPに書き出せます。
  PCでは保存先を選べるので Nextcloud の同期フォルダを直接指定でき、スマホでは共有から Nextcloud アプリへ送れます
- **復元**: ZIPを選ぶと中身(記録件数・写真枚数・作成日時)を確認してから書き戻します。
  写真を含まないバックアップから復元しても、端末の写真は消えません
- **メニューの整理**: 登録したメニューの名前・カロリーを直したり、間違えて登録したものを消せます

## ファイル構成

```
slimquest/
├── index.html          全画面のHTML + エラー捕捉
├── sw.js               Service Worker(ネットワーク優先)
├── manifest.json       PWA設定
├── version.json        更新検出用(sync-version.js が生成)
├── css/style.css
├── js/
│   ├── version.js      バージョンと更新履歴
│   ├── db.js           IndexedDB ヘルパー
│   ├── foods.js        同梱の食品データ(約170件)
│   ├── calc.js         日付・かな正規化・BMR・METs などの純粋関数
│   ├── menus.js        メニューDB(検索・頻出ランキング)
│   ├── ai.js           AI検索・バーコード照会・献立提案(Anthropic API)
│   ├── combo.js        セット/レシピの共通部品
│   ├── meals.js        食事の記録・食事日記・セット
│   ├── recipes.js      レシピ登録
│   ├── barcode.js      バーコード読み取りと照会
│   ├── weight.js       体重の記録とSVGグラフ
│   ├── exercise.js     運動の記録
│   ├── pantry.js       手持ち食材と食材の入力履歴
│   ├── shopping.js     買い物リスト
│   ├── suggest.js      献立の提案
│   ├── belly.js        お腹の定点撮影と変化ビュー
│   ├── streak.js       連続記録とバッジ
│   ├── backup.js       ZIPバックアップ / 復元(MiniZip)
│   └── app.js          画面遷移・プロフィール・ホーム(最後に読み込む)
├── tools/sync-version.js
└── docs/implementation-notes.md   実装の詳細(作業前にまず読む)
```

## リリース手順

1. `js/version.js` の `APP_VERSION` を上げ、`CHANGELOG` の**先頭**に変更を追加する
2. `node tools/sync-version.js` を実行(version.json の更新と、JS/CSS参照への `?v=` 付与)
3. `sw.js` の `CACHE_VERSION` を上げる
4. `docs/implementation-notes.md` を更新する
5. commit して push

## 注意

カロリーや消費エネルギーはすべて概算です。医学的な助言ではありません。
体調を見ながら無理のない範囲で使ってください。
